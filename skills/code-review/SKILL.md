---
name: code-review
description: 按规范审查代码质量,产出结构化审查报告(示例技能包)
---

当用户要求"审查代码"或你要对改动做质量把关时,启用本技能:

1. 用 Glob/Grep 定位待审查文件,ReadFile 通读关键文件;
2. 按以下维度审查,逐条给出 严重程度 + 位置 + 理由 + 建议:
   - 正确性:逻辑错误、边界条件、异常路径
   - 安全性:注入、敏感信息、权限校验
   - 可维护性:命名、重复、复杂度、死代码
   - 性能:不必要的重复计算、无效 I/O
3. 输出结构化审查报告:总体结论 → 问题清单(按严重程度降序)→ 改进建议。

不要擅自修改代码,除非用户明确要求修复。
