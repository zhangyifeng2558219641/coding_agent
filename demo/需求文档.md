## 1. 项目概述

### 1.1 项目背景
本项目是一个功能完整的 B2C 在线商城网页,覆盖商品展示、购物车、下单购买、在线支付、订单管理、商品评分以及积分体系等核心电商功能,同时提供管理员后台用于商品与订单的运营管理。

### 1.2 项目目标
- 为用户提供「浏览 → 加购 → 下单 → 支付 → 收货后评分 → 查看历史订单」的完整购物闭环。
- 为管理员提供「商品上架/下架、查看全部订单、调整全体用户积分」的运营能力。
- 引入积分体系:用户可通过消费获得积分,购物时可用积分抵扣金额;管理员可对任意用户发放/扣除积分。

### 1.3 目标用户
- **普通用户(买家)**:注册、登录后进行购物、评分与积分管理。
- **管理员**:管理商品与订单,控制用户积分。

---

## 2. 角色与权限

| 角色 | 说明 | 核心权限 |
| --- | --- | --- |
| 游客(未登录) | 未注册或未登录的用户 | 浏览商品列表、查看商品详情 |
| 普通用户 | 已注册并登录 | 游客全部权限 + 加购物车、下单、支付、评分、查看历史订单、使用/获得积分 |
| 管理员 | 系统运营人员(角色标识为 ADMIN) | 全部用户权限 + 上架/下架商品、编辑商品、查看所有订单、调整任意用户积分 |

> 权限控制原则:所有涉及个人数据(购物车、订单、积分)的接口必须校验登录身份;管理员接口必须校验角色为 ADMIN,防止越权。

## 3. 功能需求

### 3.1 用户端功能(普通用户)

#### 3.1.1 账号与登录
- 支持手机号/邮箱 + 密码注册。
- 注册成功即成为普通用户,自动获得初始积分(建议 0 分,可配置)。
- 登录后签发会话凭证(Token),用于后续接口鉴权。
- 支持退出登录。

#### 3.1.2 商品浏览
- 商品列表页:展示商品封面图、名称、价格、销量、评分、上架状态(仅展示「已上架」商品)。
- 支持按分类筛选、按关键词搜索、按价格/销量/评分排序。
- 商品详情页:展示完整信息(图片、描述、库存、单价、累计评分)、已有评价列表。

#### 3.1.3 购物车
- 将商品加入购物车(可指定数量,数量不能超过库存)。
- 查看购物车列表(含小计与合计)。
- 修改购物车中商品数量、删除购物车项、清空购物车。
- 购物车数据按用户隔离(每个用户只能看到自己的购物车)。

#### 3.1.4 下单购买
- 从购物车勾选商品结算 / 在商品详情页直接购买。
- 下单时确认收货地址、商品清单、金额明细。
- 生成订单,状态流转:`待支付 → 已支付(待发货) → 已发货 → 已完成`。
- 下单后对应商品库存扣减;取消未支付订单时恢复库存。

#### 3.1.5 支付
- 支持模拟支付(页面点击「确认支付」即可完成,金额校验)。
- 支付时**可使用积分抵扣**现金(见第 4 章积分规则)。
- 支付成功后订单状态变更为「已支付」。
- 未支付订单超时(如 30 分钟)自动取消并恢复库存(可选实现)。

#### 3.1.6 商品评分(评价)
- 仅**已完成的订单**中的商品允许评分。
- 评分维度:1~5 星(可附文字评价)。
- 每个用户对同一订单中的同一商品只能评价一次。
- 评分后商品平均分与评价列表实时更新。

#### 3.1.7 历史订单
- 我的订单页:按状态(全部/待支付/已支付/已发货/已完成/已取消)查看自己的订单列表。
- 订单详情:商品明细、金额明细(含积分抵扣)、收货信息、订单状态、操作按钮。
- 支持的操作:去支付、取消订单、确认收货(标记已完成)、查看评价入口。

#### 3.1.8 积分查询
- 个人中心展示当前可用积分与积分明细(获得/消费记录,含来源、时间)。

### 3.2 管理员端功能

#### 3.2.1 商品管理
- 新增商品(名称、分类、图片、描述、原价/现价、库存)。
- 编辑商品(修改价格、库存、描述、图片等)。
- **上架 / 下架商品**:下架后普通用户在商城列表不可见、不可加购(购物车中已存在的下架商品结算时提示)。
- 查看全部商品(含已下架)及库存、销量、评分等统计信息。

#### 3.2.2 订单管理
- 查看**所有用户**的订单列表,支持按订单号/用户名/状态/时间筛选。
- 查看任意订单详情。
- 可选:后台代为发货、处理退款/取消等。

#### 3.2.3 积分管理
- 查看全部用户及其当前积分余额。
- **对任意用户发放 / 扣除积分**(如运营奖励、违规扣分),可填写调整原因。
- 调整记录进入该用户的积分明细,可追溯。

## 4. 积分体系设计

### 4.1 积分规则
| 场景 | 规则 |
| --- | --- |
| 获得积分 | 用户每支付完成 1 笔订单,按订单实付金额获得积分(如每消费 1 元 = 1 积分,比例可配置);管理员手动发放 |
| 使用积分 | 支付时可选使用积分抵扣,抵扣规则建议:**100 积分 = 1 元**(比例可配置),单笔抵扣上限不得超过订单金额的 50% 或一个可配置上限 |
| 抵扣失败 | 积分余额不足或超过抵扣上限时提示用户,不允许超额抵扣 |
| 积分回退 | 订单取消 / 退款时,按规则退回已获得或已使用的积分(可选实现) |
| 积分不可转让 | 积分仅限本人账户使用,不可提现、不可转账 |

### 4.2 积分明细
- 每次积分变动(获得、使用、管理员调整)均生成一条积分流水:
  - 流水号、用户 ID、变动类型(获得/消费/管理员调整)、变动数量(±)、余额快照、关联订单号、说明、时间。

### 4.3 积分结算优先级
1. 计算商品应付金额(订单小计 - 优惠 = 应付金额)。
2. 用户在支付页输入拟使用积分数量(自动换算抵扣金额)。
3. 系统校验:积分余额充足、抵扣金额 ≤ 应付金额、抵扣金额 ≤ 抵扣上限。
4. 最终实付 = 应付金额 − 积分抵扣金额,同时扣减用户积分。
5. 支付成功后,再按「实付金额」计算本次获得积分并发放。

## 5. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 商品列表接口响应时间 < 500ms(1000 商品量级);下单/支付接口事务性完整 |
| 一致性 | 下单扣库存、支付扣积分、积分发放等关键操作必须保证数据一致性(事务) |
| 安全 | 密码加密存储(BCrypt);接口鉴权(Token);管理员接口角色校验;防止越权访问他人订单/购物车;输入校验与防 SQL 注入 |
| 可用性 | 前端 SPA 单页应用,页面刷新不丢失登录态;后端提供清晰的 REST API 与错误码 |
| 兼容性 | 支持主流浏览器(Chrome / Edge / Firefox 最新版) |
| 可维护性 | 前后端分离,代码结构清晰,数据库可初始化脚本一键建库 |

## 6. 数据模型(核心实体)

| 实体 | 关键字段(示例) |
| --- | --- |
| user | id, username, password(加密), nickname, email, phone, role(USER/ADMIN), points(当前积分), created_at |
| product | id, name, category, description, image_url, price, stock, sales, avg_rating, status(ON_SALE/OFF_SHELF), created_at, updated_at |
| cart_item | id, user_id, product_id, quantity, created_at |
| order | id, order_no, user_id, total_amount(应付), discount_points(抵扣积分), discount_amount(抵扣金额), actual_amount(实付), status, address, receiver, phone, created_at, paid_at |
| order_item | id, order_id, product_id, product_name(快照), price(快照), quantity |
| review | id, user_id, order_id, product_id, rating(1-5), content, created_at |
| point_record | id, user_id, type(GAIN/SPEND/ADMIN), points(±), balance(快照), order_id, remark, created_at |

> 订单商品项采用**快照**(下单时商品名称与单价拷贝进订单),避免后续改价影响历史订单。

## 9. 验收标准(核心场景)

1. **购物闭环**:游客注册 → 登录 → 浏览商品 → 加购 → 结算下单 → 支付 → 订单变为已支付 → 收货 → 评价,全程可完成且数据正确。
2. **购物车**:加购/改数量/删除/清空均生效,且不同用户购物车互相隔离。
3. **库存**:下单扣减库存,超库存数量不可加购/下单,取消订单恢复库存。
4. **积分**:
   - 支付时使用积分抵扣,实付金额正确、积分余额正确扣减;
   - 支付成功后按实付金额获得积分并生成积分流水;
   - 管理员可对任意用户发放/扣除积分,用户积分明细可查;
   - 积分不足或超上限时支付被正确拦截。
5. **评分**:仅已完成订单可评价,每用户每商品单次,评价后商品平均分更新。
6. **管理员**:
   - 上架/下架商品实时生效(下架后用户端不可见、不可买);
   - 可查看所有用户订单;
   - 可调整任意用户积分。
7. **权限安全**:未登录访问受保护接口返回 401;普通用户访问管理员接口返回 403;用户无法查看他人订单/购物车。
