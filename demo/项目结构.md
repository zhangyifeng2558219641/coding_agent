## 1. 项目总览

| 项 | 说明 |
| --- | --- |
| 项目名称 | 在线商城系统(含积分体系) |
| 前端 | Vue 3 + Vite 5 + Vue Router 4 + Axios + Pinia,端口 **5174**,`/api` 代理到 8082 |
| 后端 | Spring Boot 3.2.5 + Maven + Java 21,端口 **8082** |

    │       │   ├── CartController.java     # 购物车增删改查/清空

    │       │   ├── AddCartRequest / UpdateCartRequest / CartItemView

    │       ├── entity/                     # 实体(7 个,对应 7 张表)
    │       │   ├── User.java               # 用户
    │       │   ├── Product.java            # 商品
    │       │   ├── CartItem.java           # 购物车项
    │       │   ├── Order.java              # 订单
    │       │   ├── OrderItem.java          # 订单明细(名称/单价快照)

### 2.1 请求处理链路

```
HTTP 请求
  → AuthInterceptor(校验 JWT / 角色,放行公开接口)
    → Controller(参数绑定 + DTO 校验)
      → Service(业务逻辑,事务 @Transactional)
        → Repository(JdbcTemplate SQL)
          → H2 数据库
    → 异常 → GlobalExceptionHandler(统一错误 JSON)
```

### 2.2 数据库表(7 张,见 schema.sql)

| 表 | 说明 | 关键字段 |
| --- | --- | --- |
| `app_user` | 用户 | username, password_hash(BCrypt), nickname, email, phone, role, points, created_at |
| `product` | 商品 | name, category, description, image_url, price, stock, sales, avg_rating, status(ON_SALE/OFF_SHELF) |
| `cart_item` | 购物车项 | user_id, product_id, quantity |
| `mall_order` | 订单 | order_no, user_id, total_amount, discount_points, discount_amount, actual_amount, status, receiver, phone, address, paid_at |
| `order_item` | 订单明细 | order_id, product_id, product_name(快照), price(快照), quantity, reviewed |
| `review` | 评价 | user_id, order_id, product_id, rating(1-5), content |
| `point_record` | 积分流水 | user_id, type(GAIN/SPEND/ADMIN), points(±), balance(快照), order_id, remark |

## 3. 前端结构 `frontend/`

```
frontend/
├── package.json              # 依赖:vue / vue-router / pinia / axios;scripts: dev / build / preview
├── package-lock.json         # 依赖锁文件
├── vite.config.js            # 端口 5174 + /api 代理到 http://localhost:8082
├── index.html                # 入口 HTML
├── run-vite.log              # Vite 运行日志(运行时生成)
├── dist/                     # 构建产物(npm run build 生成)
├── smoke_m3.sh               # M3 端到端冒烟脚本(走 5174 代理)
└── src/
    ├── main.js               # 应用入口:创建 app,挂载 Pinia / Router
    ├── App.vue               # 根组件:顶栏(登录态/积分/管理入口)+ 路由出口
    ├── style.css             # 全局样式
    ├── api/                  # API 封装(6 个)
    │   ├── request.js        # Axios 实例:附加 token、401 跳登录、统一错误提示
    │   ├── auth.js           # 注册/登录/me
    │   ├── user.js           # 资料/密码
    │   ├── products.js       # 商品列表/详情/分类/评价
    │   ├── cart.js           # 购物车接口
    │   ├── order.js          # 订单/支付/取消/收货/评价/积分流水
    │   └── admin.js          # 管理端:商品/订单/用户/积分/看板
    ├── router/
    │   └── index.js          # 路由表 + 全局守卫(requiresAuth / guestOnly / requiresAdmin)
    ├── store/
    │   └── user.js           # Pinia:登录态(token/user)、登录/退出、积分显示
    └── views/                # 页面组件(12 个)
        ├── Home.vue              # 首页:商品列表(分类/关键词/排序筛选)
        ├── ProductDetail.vue     # 商品详情:信息 + 评价列表 + 加入购物车
        ├── Login.vue / Register.vue  # 登录 / 注册
        ├── Profile.vue           # 个人中心:资料/修改密码/积分入口
        ├── Cart.vue              # 购物车:改量/删除/结算弹窗(收货信息+积分抵扣)
        ├── OrderList.vue         # 我的订单:状态筛选 + 详情/支付/取消/收货/评价弹窗
        ├── Points.vue            # 积分明细
        ├── AdminDashboard.vue    # 数据看板:销售额/订单/用户/商品/热门 TOP5/最近订单
        ├── AdminProducts.vue     # 商品管理:CRUD + 上下架
        ├── AdminOrders.vue       # 订单管理:全部订单 + 筛选/搜索 + 详情 + 发货
        └── AdminUsers.vue        # 用户管理:列表 + 调整积分 + 积分明细
```

### 3.1 前端路由(12 条)

| 路由 | 页面 | 权限 |
| --- | --- | --- |
| `/` | 首页(商品列表) | 公开 |
| `/product/:id` | 商品详情 | 公开 |
| `/login`、`/register` | 登录 / 注册 | 仅游客 |
| `/profile` | 个人中心 | 登录 |
| `/cart` | 购物车 | 登录 |
| `/orders` | 我的订单 | 登录 |
| `/points` | 积分明细 | 登录 |
| `/admin` | 数据看板 | ADMIN |
| `/admin/products` | 商品管理 | ADMIN |
| `/admin/orders` | 订单管理 | ADMIN |
| `/admin/users` | 用户管理 | ADMIN |

### 3.2 前端请求流程

```
Vue 组件(views/)
  → api/*.js(函数封装)
    → request.js(Axios 实例:baseURL=/api,拦截器)
      → /api 代理(vite.config.js)→ 后端 8082
```
